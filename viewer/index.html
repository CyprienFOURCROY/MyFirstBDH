The text: black = already read, blue = the letter thrown now, faded = not read yet. Letters in a dashed purple box were written by the model, the others are your prompt. Click a letter to throw it.
The small letter under each one is what the model predicts next after reading it: green = right, red = wrong, purple = the open question at the end of the text.
The 4 rounds of each layer, in the order the code runs them (click one). Keys: ← → step, space = play.

One layer, one letter, round by round. Neuron i sits at position i in each row; a bigger, brighter dot means a larger value. Green lines push a neuron up, red lines pull it down (a neuron pulled below zero is cut to 0 by the ReLU, shown as a red ring). Only the strongest wires of the round are drawn.

The 4 wires the model learned. Row = the neuron that receives, column = the neuron that sends (G @ y reads row j as: neuron j receives from every column i). Bright = strong wire. Excitatory (_e) pushes up, inhibitory (_i) pushes down; the model uses their difference.

Each point is a neuron (placed evenly on a sphere: the position means nothing, only the wires do). A line joins a sender to a receiver; only the strongest ones are drawn. Big points have many strong wires. Drag to rotate, scroll to zoom.

One row per letter of the text, one column per neuron. A bright cell means that neuron is active at that letter. The bar chart counts how many neurons are active (x > 0) per letter. The last picture is the memory sigma after the whole text.
